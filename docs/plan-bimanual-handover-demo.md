## 3. Spark 주말 실행 순서 (이 순서만, 범위 밖 리팩터 금지)

각 단계 끝의 **멈춤 조건**에 걸리면 다음 단계 대신 폴백으로 간다. 산출물은 `~/openarm-out/<YYYYMMDD>/` 에 두고 **커밋하지 않는다** (영상·이미지). 텍스트 요약만 `reports/` 가 아닌 PR 설명/메시지로 전달.

| # | 단계 | 명령 / 산출물 | 멈춤 조건 → 폴백 |
|---|---|---|---|
| P0 | 환경 탐색 (설치 전) | 기존 Isaac Sim 6.x 빌드·conda env 유무, `nvidia-smi`, 드라이버(문서 권장 580.142), 디스크 ≥ 60 GB, pypi.nvidia.com 접근 | 인터넷 불가 → 사용자에게 보고하고 중단 |
| P1 | 설치 | `scripts/setup_conda_isaac.sh --pip --with-policy-env` (6.0.1.0 aarch64 휠 + torch 2.10.0 cu130). 기존 6.3 빌드는 건드리지 않음 | 2시간 내 `import isaacsim, isaaclab` 실패 → 소스 빌드 경로(`setup_conda_isaac.sh` 기본) 또는 L0 폴백 |
| P2 | 도달맵 재실행 | `python tools/reach/openarm_reach.py --urdf $OPENARM_DESC/.../v1.urdf --out ~/openarm-out/<d>/reach` | — (numpy, 항상 가능) |
| P3 | Isaac 로드 검증 | `sim/demo/handover_demo.py --dry_run_kinematics` : OpenArm USD 로드, 관절 이름·한계 출력, 어깨 프레임을 URDF 값과 대조, 웨이포인트별 IK 가능 여부 | 토요일 밤까지 USD 로드 또는 한 팔 IK 실패 → **L1 폴백** |

폴백 단계: **L0** 도달맵 SVG(numpy) → **L1** 케이블을 손에 붙인 운동학 재생(물리 없음) → **L2** 강체 케이블 물리(기본) → **L3** 캡슐 체인 케이블(시간 남을 때만).
